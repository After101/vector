# vector

  This is a custom wearable I'm working on that uses the nRF52840 featuring:
  - BLE
  - Gesture based controls
  - ST7789 raw OLED panel
  - Haptic feedback
  - Custom enclosure
  - Magnetic pogo pin charging and programming
  -  29mm x 20mm PCB 
  -  Enclosure WIP
 

  Current status:
  - PCB complete
  - Enclosure WIP
  - Firmware not done yet
