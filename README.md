# cool-watch
  This is a custom wearable I'm working on that uses the nRF52840 featuring:
  - BLE
  - Gesture based controls
  - SSD1306 OLED
  - Haptic feedback
  - Custom enclosure
  - USB-C charging
  -  34mm x 32.75mm PCB
  -  38mm x 36.75mm x 14mm Enclosure (Battery takes up a lot of thickness)
 

  Current status:
  - PCB complete
  - Enclosure complete
  - Firmware not done yet
